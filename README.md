# pi-exit

A Pi extension that adds `/exit` as an alias for Pi's built-in `/quit` command. `/quit` remains available.

## Install from GitHub

After publishing this repository, run this in your terminal:

```bash
pi install git:github.com/YoucefBenAli/pi-exit
```

Restart Pi or run `/reload` after installing.

## Try locally

From this repository, run Pi with the extension loaded:

```bash
pi --extension ./extensions/exit.ts
```

Or install the local package for your user:

```bash
pi install .
```
